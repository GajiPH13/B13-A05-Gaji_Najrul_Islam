1. What is the difference between var, let, and const?

Answer:
 Var is a function scope, reassignable and redeclarable . let and const are block scope. const is immutable.


2. What is the spread operator (...)?

Answer: 
 Unpacktin or expanding the contents of an array. It can also be used for combining array.


3. What is the difference between map(), filter(), and forEach()?

Answer:
    forEach() => loop through all items in an array and . Original value remain same return value undefined.

    map() => It change the vlaue of the element of an array and return a new array. The original array will     remain same.

    filter() => Pick and choose which items to keep. Return a new filtered array. The original array will remain same.
